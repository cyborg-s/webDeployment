Kreideheld

React | TypeScript | FastAPI | SQLAlchemy | REST API
In Development

Kreideheld is a fullstack web application for managing leftover materials in craft businesses. Employees can record material leftovers and will be able to quickly find suitable stock based on required dimensions. The project is being developed with React, TypeScript, and FastAPI and already includes a REST API, CRUD functionality, and data modeling. Multi-tenancy and an offline-first architecture are part of the ongoing development.

Kreideheld ist eine Fullstack-Webanwendung zur Verwaltung von Restmaterialien in Handwerksbetrieben. Mitarbeiter können Materialreste erfassen und sollen passende Bestände anhand benötigter Maße schnell wiederfinden. Das Projekt wird mit React, TypeScript und FastAPI entwickelt und umfasst bereits REST-API, CRUD-Funktionen und Datenmodellierung. Multi-Tenancy und eine Offline-First-Architektur befinden sich im weiteren Ausbau.
